# 仓库管理

## 上传范围

- `src/riskparity/`：统一入口、取数与来源审计、组合研究、因子分析、报告及账本。
- `outputs/asset_rotation/`：明确列在 `.gitignore` 允许清单中的算法内核、测试依赖和配置；为兼容旧研究保留路径。
- `outputs/single_asset/`：单资产模型、取数、测试和配置。
- `configs/`、`tests/`、`docs/`、`.github/`、`.vscode/` 以及根目录安装文件。

行情、因子结果、图表、报告、代码快照、第三方参考仓库、`work/`、`runs/`、`state/`、`data/`、虚拟环境和构建产物只在本地保存。整理不会删除或移动已有研究资料。

## 日常维护

```bash
python project.py test
git status --short
git diff --cached --stat
git add src configs tests docs README.md
git commit -m "Describe the research code change"
git push
```

新增兼容内核时，检查其本地导入依赖并更新 `.gitignore` 允许清单。安装包运行模块由 `build_support.py` 单独控制；历史测试辅助模块未必进入 wheel。不能用 `git add -f` 批量上传输出目录。

## 数据约定

Wind 永远为主接口。失败后允许自动切换适合标的的真实备用源，并记录失败原因、实际来源、时间范围、取数时间、复权与成交量口径。禁止无记录混拼来源。Wind 导出数据可离线使用，但不随代码仓库发布。公开样例或合成数据只能验证软件，不能用作正式绩效或当前交易结论。

## 新机器验证

按 README 安装后运行 `python project.py test`。这些测试使用软件测试数据，不需要上传本地历史行情，也不请求行情或下单。真实回测需另行取数或导入有完整来源记录的离线数据。
